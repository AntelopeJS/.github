# ![AntelopeJS](https://raw.githubusercontent.com/AntelopeJS/.github/main/res/images/header.png)

AntelopeJS is a modular Node.js framework for building applications from small,
independent modules connected through versioned interfaces.

## Get started

- Read the [framework documentation](https://antelopejs.com/).
- Explore the [`@antelopejs/core`](https://github.com/AntelopeJS/antelopejs)
  runtime and CLI.
- Browse the public packages in this organization.
- Join the [Discord community](https://discord.com/invite/yS53x6FXQj).

## DMS

DMS is built with AntelopeJS: a core runtime and interface package, plus one
module per capability, so a deployment only runs what it needs.

- [`dms`](https://github.com/AntelopeJS/dms): core runtime module and interface
  package.
- [`dms-ai`](https://github.com/AntelopeJS/dms-ai): AI assistant module.
- [`dms-api`](https://github.com/AntelopeJS/dms-api): public API module.
- [`dms-automation`](https://github.com/AntelopeJS/dms-automation): workflow
  automation module.
- [`dms-builder`](https://github.com/AntelopeJS/dms-builder): visual page
  builder module.
- [`dms-database`](https://github.com/AntelopeJS/dms-database): database browser
  module.
- [`dms-frontend`](https://github.com/AntelopeJS/dms-frontend):
  frontend-agnostic loader that materializes backend frontend modules, with a
  Vue 3 renderer today.
- [`dms-lang`](https://github.com/AntelopeJS/dms-lang): localization module.
- [`dms-mailing`](https://github.com/AntelopeJS/dms-mailing): templates, sends
  and delivery tracking.
- [`dms-marketing`](https://github.com/AntelopeJS/dms-marketing): pages,
  campaigns, funnels and analytics.
- [`dms-media`](https://github.com/AntelopeJS/dms-media): media library module.
- [`dms-saas`](https://github.com/AntelopeJS/dms-saas): multi-tenant SaaS
  module.
